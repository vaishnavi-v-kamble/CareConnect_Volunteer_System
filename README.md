🌟 About the Project

CareConnect is a volunteer coordination system being designed to help bridge the gap between people who want to contribute their time and skills and organizations or communities that need support.

The project aims to make it easier to discover volunteer opportunities, coordinate NGO activities, and keep track of participation—all through a clear and user-friendly application.

💡 Our vision: Connect willing hearts with meaningful opportunities and help turn community needs into collective action.

🎯 Objectives

🤝 Connect volunteers with NGOs and community initiatives.

📣 Make volunteer opportunities and activities easier to discover.

🗂️ Support organized management of volunteers and NGO activities.

🎯 Help match volunteers with suitable activities and needs.

📊 Support activity tracking and coordination.

📱 Build an accessible, user-friendly application experience.

✨ Planned Features

🔐 Authentication — login and registration flows.

🙋 Volunteer Management — organize volunteer profiles and information.

🏢 NGO Management — maintain NGO and organization information.

📌 Activity Management — create and manage volunteering activities.

🔎 Activity Matching — help connect volunteers with relevant activities.

📍 Activity Tracking — follow activity participation and progress.

🆘 Help / Need Management — organize community needs and requests.

🚀 Getting Started

Prerequisites

Install the following tools:

Flutter SDK

Git

Visual Studio Code or Android Studio

1. Clone the repository

git clone https://github.com/vaishnavi-v-kamble/CareConnect_Volunteer_System.git
cd CareConnect_Volunteer_System

2. Install dependencies

flutter pub get

3. Check available devices

flutter devices

4. Run the application

For a connected Android device or emulator:

flutter run

To run in Chrome (if web support is enabled):

flutter run -d chrome

Since the project is under active development, the initial app may still display the default Flutter starter screen while features are being built.

👩‍💻 Team Collaboration

CareConnect is maintained through GitHub to support collaborative development.

Suggested workflow:

Clone the repository.

Create a separate branch for your task.

Make and test your changes.

Commit and push your branch.

Open a pull request for review before merging into main.

Example:

git checkout -b feature/your-feature
git add .
git commit -m "Add your feature"
git push -u origin feature/your-feature

Please coordinate before changing shared files such as main.dart or pubspec.yaml, and pull the latest changes before starting new work.

Small acts of kindness can create meaningful change. By bringing volunteers and organizations together in one coordinated system, CareConnect aims to make it easier for people to find opportunities to help and for organizations to coordinate that support.
